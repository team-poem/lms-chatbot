## 1. 추진 배경

직전 품질 개선에 이어, 실사용 관점에서 두 가지 문제가 추가로 확인되었다.

1. **과잉 거절 사각지대** — "안녕하세요", "어떤 걸 가이드 해줄 수 있나요?"는 정상 응답하지만, **"LMS에 대해서?", "LMS가 뭐야?"** 같은 막연한 범위·소개 질문은 검색 게이트로 떨어져 *"확인이 어렵습니다. 문의 부탁드립니다"* 로 거절되는 사각지대가 남아 있었다.
2. **배포 환경 대화 기록 유실** — Docker로 배포한 운영 환경에서 대화 기록이 남지 않아, 보유한 기록이 없는 상태였다.

---

## 2. 추진 내용

### 2-1. 과잉 거절 사각지대 보완

LMS 전반에 대한 막연한 소개·범위 질문을 검색 게이트 *이전*에 결정적으로 분기하여, 거절 대신 챗봇 소개로 응대하도록 보완하였다.

- 신규 판별기 `is_scope_question` 추가: **대상(LMS) + 막연한 표현(대해서/뭐야/소개)** 이 있고 **구체 신호(어떻게·방법·과제·출석·오류 등)가 없을 때만** 발화하는 보수적 규칙
- 구체 질문("LMS에서 과제 제출은 어떻게 하나요?")은 그대로 검색 경로로 보내, 진짜 질문이 일반 소개로 가로채이지 않도록 안전장치 적용

| 입력 예 | 수정 전 | 수정 후 |
|---------|---------|---------|
| `안녕하세요` | 정상(인사 응답) | 정상(인사 응답) |
| `어떤 걸 가이드 해줄 수 있나요?` | 정상(안내 리스트업) | 정상(안내 리스트업) |
| `LMS에 대해서?` | **거절** | **챗봇 소개 응답** |
| `LMS가 뭐야?` | 거절 | 챗봇 소개 응답 |
| `LMS에서 과제 제출은 어떻게 하나요?` | 검색 응답 | 검색 응답(불변) |

### 2-2. 배포 환경 대화 기록 유실 수정

근본 원인을 두 가지로 진단하고 모두 수정하였다.

| 구분 | 결함 | 근본 원인 | 조치 |
|------|------|-----------|------|
| 인프라 | 컨테이너 재시작 시 기록 유실 | SQLite DB를 **단일 파일**로 컨테이너에 연결 → 트랜잭션 보조 파일이 호스트에 보존되지 않아 기록이 유실 | 로그 **전용 폴더**를 연결하도록 전환(DB와 보조 파일이 함께 호스트에 보존) |
| 응용 | 재방문자 응답 거부 + 무기록 | 브라우저가 만료된 과거 세션을 서버 확인 없이 재사용 → 서버가 거부(403), 기록도 남지 않음 | 세션 만료 감지 시 자동으로 재동의를 유도해 새 세션을 발급 |

### 2-3. 로그 조회 수단 구축

기록을 직접 확인·반출할 수단이 없던 문제를 함께 해소하였다.

- 관리자 전용 조회 API 추가 (토큰 인증, JSON/CSV 내보내기 지원)
- 인증 토큰 미설정 시 비활성화되어 외부 노출 위험 차단

### 2-4. 품질 보증

- 모든 수정을 테스트 우선(TDD)으로 진행
- 회귀 테스트 신규 작성: 라우팅 사각지대 4건, 로그 조회/내보내기 3건
- 전체 자동 테스트 **91건 전수 통과**

## 3. 성과

- 막연한 소개·범위 질문에 대한 **과잉 거절 제거** — 사용자가 첫 진입에서 거절을 마주치는 어색한 경험 해소
- 배포 환경에서 **대화 기록이 정상 보존**되도록 구조 개선 (재시작·DB 초기화에도 누적 보존)
- **기록 조회·반출 수단 확보** — 운영 데이터 점검 및 후속 품질 분석 기반 마련
- 회귀 테스트로 고정하여 재발 방지
