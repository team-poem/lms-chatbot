# 메뉴 → 가이드 문서 뷰어 설계

작성일: 2026-06-08

## 배경

첫 진입 카탈로그 메뉴는 항목을 자유질문으로 /chat(RAG)에 보냈다. 그 결과 질문형 항목이 FAQ DB(이미지 없음·짧음)나 이미지 없는 인트로 섹션을 검색 1위로 잡아, 이미지 풍부한 가이드 매뉴얼이 컨텍스트에 안 들어왔다. 색인엔 이미지가 있는데도(496청크 중 187개 보유) 답변에 거의 안 붙고 설명도 짧았다.

해결: 메뉴 항목을 특정 매뉴얼 문서에 매핑하고, 클릭하면 그 문서의 본문·이미지·출처를 그대로(verbatim) 보여준다. 검색 경쟁을 우회한다.

## 목표

- 메뉴 항목 클릭 시 매핑된 가이드 문서의 실제 본문 + 이미지 전부 + 출처 링크를 표시한다.
- AI 생성 없음(요약·환각·LLM 지연 없음).
- 자유 입력 질문은 기존 RAG/QnA 경로 그대로 둔다.

## 비목표

- 답변 라우팅(메타 거절 → 검색 게이트 → 매뉴얼 답변 / QnA 폴백)은 바꾸지 않는다.
- 이미지를 본문 위치에 인라인 배치하지 않는다(본문 뒤 그리드로 모아 표시 — 기존 답변 렌더 재사용).
- 통합 항목은 대표 문서 1개에만 연결한다(여러 문서 병합 안 함).

## 아키텍처

### 1. 데이터(인제스트·색인) — 청크에 두 필드 추가
- `doc_title: str` — 페이지 제목(섹션 접미사·(j/n) 없는 원 제목). `_derive_title(path)` 결과. 같은 문서의 모든 청크가 공유. 항목→문서 매핑 키.
- `seq: int` — 문서 내 청크 순서(인제스트가 문서 단위로 청크를 만들 때 0,1,2…). 문서 재조립 시 정렬용.
- `app_types.Chunk`, `ingest/chunk.py`(부여), `index/vector_store.py`·`retrieval` 메타 저장·복원에 반영. 재인덱싱 1회 필요.

### 2. 카탈로그 — 항목이 (label, doc) 구조
- `generation/catalog.py`의 항목을 문자열에서 `CatalogItem(label, doc)`로 변경.
  - `label`: 사용자에게 보이는 문구.
  - `doc`: 표시할 매뉴얼 페이지 제목(정확한 doc_title).
- `catalog_as_dict()`는 항목을 `{"label":..., "doc":...}`로 직렬화.

### 3. 가이드 조립 + 엔드포인트
- 순수 함수 `build_guide(chunks, doc_title) -> dict | None`: 해당 doc_title 청크를 `seq` 순으로 정렬해 본문 이어붙임, 이미지 등장순 중복제거, 출처는 notion_url. 없으면 None.
- `GET /guide?doc=<제목>` → 200 `{ "title", "text", "images": [...], "source_url" }`, 못 찾으면 404.
- chroma에서 doc_title로 청크를 가져와 build_guide에 넘긴다(예: collection.get(where={"doc_title": doc})). 세션·인증 불필요(공개 가이드).

### 4. 프런트(static/index.html)
- 카탈로그 항목 버튼: 표시 텍스트는 `label`, 클릭 시 `showGuide(doc, label)` 호출.
- `showGuide`: 답변 버블을 하나 만들고(질문줄에 label 표시) `GET /guide?doc=` 호출 → `.a`에 text, `.imgs`에 images, `.src`에 source_url 렌더(기존 렌더 구조 재사용).
- 404/실패 시 기존 `ask(label)`(RAG)로 폴백(graceful degradation).
- 자유 입력창·기존 ask() 경로는 그대로.

## 테스트

- 청커: doc_title 이 같은 문서의 모든 청크에서 동일하고 섹션 접미사가 없는지, seq 가 0부터 증가하는지.
- 색인 저장·복원: doc_title·seq 가 메타에 저장되고 복원되는지.
- build_guide: seq 순으로 본문 이어붙이고 이미지 등장순 중복제거, 없는 doc 은 None.
- 카탈로그: 항목이 label·doc 을 갖고, catalog_as_dict 가 {label,doc} 로 직렬화하는지.
- 매핑 정합성: 모든 카탈로그 doc 이 data/raw 매뉴얼의 실제 doc_title 집합에 존재하는지(오타 가드, data/raw 읽어 검증).
- 엔드포인트: GET /guide?doc=<실제 제목> 200 + 구조, 없는 doc 404.
- 프런트는 라이브 스모크(클릭 → 본문·이미지·출처, 404 폴백).

## 영향 범위 (파일)

- `app_types.py` — Chunk.doc_title, Chunk.seq
- `ingest/chunk.py` — doc_title·seq 부여
- `index/vector_store.py`, `retrieval/search.py` — 메타 저장·복원(_chunk_meta/_chunk_from_meta)
- `generation/catalog.py` — CatalogItem(label, doc) 구조 + 매핑
- `generation/guide.py`(신규) — build_guide 순수 함수
- `backend.py` — GET /guide
- `static/index.html` — showGuide + 항목 클릭 연결 + 404 폴백
- 테스트: test_chunk, test_vector_store/test_search, test_catalog, test_guide(신규), test_backend(또는 test_catalog)
