# 첫 진입 카탈로그 메뉴 설계

작성일: 2026-06-07

## 배경

매뉴얼 전용 + QnA 폴백으로 전환한 뒤, 인사나 "뭘 도와줄 수 있냐" 같은 입력이 전부 QnA로 안내돼 사용자가 진입점을 찾기 어려웠다. 답변 정책(매뉴얼 근거만)은 유지하되, 사용자가 무엇을 물어볼 수 있는지 첫 화면에서 바로 보이도록 카탈로그 메뉴를 추가한다.

## 목표

- 대화창 첫 진입(동의 후) 시 카테고리 메뉴를 바로 보여준다.
- 카테고리를 고르면 그 안의 세부 항목(실제 매뉴얼 주제)을 펼쳐 보여준다.
- 항목을 고르면 그 질문이 평소 답변 경로(검색→매뉴얼 답변)로 처리된다.
- 메뉴 항목은 실제 매뉴얼 문서에서 큐레이션해, 고르면 근거가 잡혀 QnA로 빠지지 않는다.

## 비목표

- 답변 라우팅(generation/stream.py: 메타 거절 → 검색 게이트 → 매뉴얼 답변 / QnA 폴백)은 바꾸지 않는다.
- 입력 말투·의도 감지는 하지 않는다. 메뉴는 UI 진입점일 뿐이다.
- QnA 폴백 정책은 그대로다(메뉴 밖 자유 질문은 기존대로 매뉴얼/QnA).

## 아키텍처

세 조각으로 구성한다.

1. 카탈로그 데이터 (백엔드, 큐레이션) — `generation/catalog.py`에 카테고리·항목을 정적 정의한다. 176개 문서에서 큐레이션한 단일 출처.
2. 카탈로그 엔드포인트 — `GET /catalog` 가 카탈로그를 JSON 으로 반환한다(공개, 인증 불필요, 세션 불필요).
3. 첫 진입 메뉴 (프런트) — `static/index.html` 이 동의 후 `/catalog` 를 불러 `#log` 의 안내 문구 자리에 카테고리 버튼을 렌더한다. 드릴다운은 클라이언트에서 처리한다.

답변 흐름은 그대로다. 메뉴 항목 클릭 = 그 텍스트를 질문으로 `ask()` 에 넘기는 것뿐이며, 이후는 기존 `/chat` → 검색 → 매뉴얼 답변 경로를 탄다.

## 카탈로그 데이터 구조

`generation/catalog.py`:

```python
@dataclass(frozen=True)
class CatalogCategory:
    emoji: str
    name: str
    items: tuple[str, ...]   # 사용자가 고르면 그대로 질문으로 전송되는 문구

CATALOG: tuple[CatalogCategory, ...] = (...)

def catalog_as_dict() -> dict:
    return {"categories": [{"emoji": c.emoji, "name": c.name, "items": list(c.items)} for c in CATALOG]}
```

`items` 의 각 문자열은 화면 라벨이자 클릭 시 전송되는 질문이다. 실제 문서 제목 기반이라 검색에서 근거가 잡힌다.

## 엔드포인트

`GET /catalog` → 200, `{"categories": [{"emoji", "name", "items": [...]}, ...]}`. 인증·세션 불필요. 정적 데이터라 항상 동일.

## 프런트 동작 (static/index.html)

- 동의 완료로 세션이 활성화되면(기존 입력 활성화 시점) `/catalog` 를 fetch 한다.
- `#log` 의 기본 안내 문구(`<p class="empty">`)를 카테고리 버튼 목록으로 대체한다.
- 카테고리 클릭 → 그 카테고리의 항목 버튼들을 펼친다(클라이언트 측, 추가 네트워크 호출 없음). 다른 카테고리로 전환 가능.
- 항목 클릭 → `ask(항목텍스트)` 호출(기존 함수 재사용). 이후 답변·이미지·출처·피드백은 기존 흐름.
- 자유 입력창은 그대로 유지한다.
- `/catalog` fetch 실패 시 기존 안내 문구를 그대로 두고(메뉴 없이) 자유 입력만 가능하게 둔다(graceful degradation).

## 테스트

- `generation/catalog.py`: CATALOG 가 비어있지 않고, 각 카테고리에 name·items(1개 이상)가 있으며, `catalog_as_dict()` 구조가 올바른지.
- 엔드포인트: `GET /catalog` 가 200 과 categories 배열을 반환하는지(FastAPI TestClient).
- 프런트는 단위 테스트 대상 아님 — 라이브 스모크로 확인(첫 진입 메뉴 표시 → 카테고리 → 항목 클릭 → 매뉴얼 답변).

## 비고

- 답변 라우팅·QnA 폴백·이미지 격리는 이전 작업 그대로 유지.
- 카탈로그는 정적 큐레이션이라 매뉴얼이 크게 바뀌면 수동 갱신한다(파일 상단에 명시). 자동 생성은 후속 과제 후보.
- QA 하니스 재설계는 여전히 별도 과제.
