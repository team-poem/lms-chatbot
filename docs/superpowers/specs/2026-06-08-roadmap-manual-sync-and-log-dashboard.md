# 로드맵 — 매뉴얼 싱크 파이프라인 & 대화로그 대시보드

작성일: 2026-06-08
상태: **계획만** (구현 전 기록용). 우선순위·방식은 추후 brainstorming 후 확정.

배포 환경: 맥미니(Apple Silicon) + Docker Desktop, 호스트 native Ollama(gemma3:4b),

## 1. 노션 매뉴얼 → 챗봇 반영 파이프라인

### 문제
노션 교수자 매뉴얼이 바뀌어도 챗봇 인덱스(chroma + bm25 + assets)는 수동 재인덱싱
해야만 반영된다. 담당 선생님이 코드/CLI 없이 갱신할 수 있어야 한다.

### 접근 A — 맥미니 서버에 "매뉴얼 주입" 뷰어 (담당자 직접 업로드)
- 맥미니 서버에 관리 UI를 두고, 담당 선생님이 노션 export(zip)를 업로드.
- 업로드 → 서버가 unzip → `run_ingest` 실행 → 새 인덱스로 교체(atomic swap).
- 장점: 담당자가 즉시·자율적으로 갱신. 노션 API 권한 불필요.
- 고려사항:
  - 인증(누가 업로드 가능한가) — `ADMIN_TOKEN` 류 게이트.
  - 인덱싱 중 무중단: 새 인덱스를 별 디렉터리에 빌드 후 심볼릭/경로 스왑, 또는
    빌드 완료 후 컨테이너가 재로드(현재 RagState 는 기동 시 1회 로드 → 재로드 트리거 필요).
  - 업로드 검증(빈 export·형식 오류 시 기존 인덱스 보존).

### 접근 B — 스케줄 전체 추출 + 변경분만 싱크
- 노션 API/주기적 export 로 전체 매뉴얼을 스케줄마다 받아오고, 한 번 재정렬(청킹)
  들어간 뒤 **변경된 문서만** 싱크.
- 변경 감지: 문서별 콘텐츠 해시(또는 노션 last_edited_time) 비교 → 바뀐 청크만
  upsert/삭제. 현재 `run_ingest` 는 `reset_collection` 후 전체 재빌드라, 증분 싱크로
  바꾸려면 chroma upsert/delete by id + bm25 부분 갱신 설계 필요.
- 장점: 사람 개입 없이 자동 최신화.
- 고려사항:
  - 노션 export 자동화(공식 API는 블록 단위 — 현재 인제스트는 마크다운 export 전제).
  - bm25 는 전체 코퍼스로 재빌드해야 정확(부분 갱신 시 idf 흔들림) → 증분이라도
    bm25 는 전체 재빌드가 단순·안전.
  - 이미지 assets 동기화(추가/삭제).

### 공통 메모
- 현재 인덱싱 산출물: `data/chroma`, `data/bm25.pkl`, `data/assets` (+ `data/raw`).
  이미지 경로 정규식 버그 수정으로 재인덱싱 필요(2026-06-08). **이미지 추출은
  괄호 포함 경로를 처리하는 정규식에 의존**하므로 노션 폴더명 변경 시 회귀 주의.
- 목차(TOC)/부모 인덱스 페이지는 자동 제외(`_is_index_page`) — 노션 구조가 바뀌면
  이 규칙(제목=형제폴더명+자식.md) 유효성 재확인.
- 권장: 1차로 **접근 A**(담당자 업로드)가 운영 부담이 적고 즉효. 접근 B(증분 자동)는
  안정화 후 도입.

## 2. 대화 로그 대시보드 (뷰어)

### 현재
- 모든 turn 이 SQLite(`data/logs/chat_logs.db`, 컨테이너 기준)에 기록:
  질문·응답·출처·검색점수·latency·시각, 그리고 피드백(예/아니오).
- 조회 수단: `GET /admin/logs`(json/csv, `ADMIN_TOKEN` 헤더/쿼리 인증). 화면 없음.

### 계획 — 웹 대시보드
- 로그를 표로 브라우징: 질문, 응답, 출처, 점수, latency, 시각, 피드백.
- 필터/검색: 기간, 폴백 여부, 부정 피드백, 저점수.
- 인사이트: **폴백·부정 피드백이 잦은 질문** = 매뉴얼 보강 우선순위 도출
  (원래 로깅 목적과 직결).
- 인증: `/admin/logs` 와 동일 토큰 게이트 재사용.
- 구현 옵션: 정적 페이지 + `/admin/logs` JSON 소비(가장 단순), 또는 별도 관리 SPA.

### 고려사항
- 개인정보처리방침상 보유기간(6개월)·동의 철회(purge) 와 일관.
- 시각은 UTC 저장 → 대시보드에서 KST 표시.
