# 업무성과보고서

## LMS 교수자 응대 챗봇 — 응답 품질 검증 및 개선

| 항목 | 내용 |
|------|------|
| 보고일 | 2026-06-01 |
| 대상 시스템 | 동서대학교 LearningX LMS 교수자 응대 AI 챗봇 (RAG 기반) |

| 담당 | 1인 수행 (검증 설계 → 진단 → 수정 → 배포) |

---

## 1. 추진 배경 및 목적

LMS 사용법 문의에 자동 응대하는 교수자용 챗봇의 실제 응답 품질을 객관적으로 검증할 체계가 없어, 배포 전 신뢰성을 보장하기 어려운 상태였다. 이에 **실제 교수자 FAQ 80문항을 챗봇에 자동 입력하여 응답 품질을 정량 검증**하고, 발견된 결함을 수정하여 실서비스 가능 수준으로 끌어올리는 것을 목표로 하였다.

---

## 2. 추진 내용

### 2-1. 응답 품질 자동 검증 체계 구축
- 교수자 FAQ 원본(80문항)을 검증 데이터셋으로 정형화
- 브라우저 기반 E2E 자동 검증으로 80문항 전수 응답 수집 (동의 절차 → 질의 → 스트리밍 응답)
- 응답 로그(DB)에서 질의·응답·검색점수·지연시간을 추출하여 정량 분석
- 다관점 자동 채점(주제 일치·사실 정확성·규칙 준수)을 적대적 교차검증과 결합하여 오탐 제거

### 2-2. 결함 진단 및 수정
검증 결과 확정된 결함을 근본 원인까지 추적하여 수정하였다.

| 구분 | 결함 | 근본 원인 | 조치 |
|------|------|-----------|------|
| 중대 | 분류 메타데이터가 답변에 노출 | 문서 메타헤더가 본문에 함께 색인됨 | 색인 전처리에서 메타헤더 제거 |
| 중대 | 무관 문서로 인한 오답 | 유사 주제 문서가 답변 근거에 혼입 | 근거 문서 수 제한 + 관련도 기준 강화 |
| 구조 | 검색 노이즈(전체의 44%) | 답변 없는 색인 항목 과다 생성 | 해당 항목 색인 제외 |
| 구조 | 재색인 시 과거 데이터 잔존 | 색인 갱신 로직의 멱등성 결함 | 재색인 전 색인 초기화 |
| 품질 | 출처 목록에 무관 문서 노출 | 근거 문서를 그대로 출처로 표시 | 출처는 고관련 문서만 노출 |
| 품질 | 응답 규칙 위반(호칭·종결어·서식) | 원문 말투를 생성 모델이 일부 답습 | 응답 후처리로 규칙 위반 결정적 차단 |

### 2-3. 품질 보증 체계 정비
- 모든 수정을 테스트 우선(TDD) 방식으로 진행
- 회귀 테스트 18건 신규 작성 (전처리·색인·검색·후처리)
- 수정 후 80문항 전수 재검증으로 효과 실측

## 3. 성과

### 정량 성과

| 지표 | 개선 전 | 개선 후 |
|------|---------|---------|
| 응답 규칙 위반 | 15건 / 80문항 | **0건** |
| 분류 메타데이터 노출 | 발생 | **0건** |
| 검색 노이즈 색인 비율 | 44% (361항목 중 160) | **0% (200항목)** |
| 출처 오염(무관 문서 노출) | 발생 | **해소** |
| 자동화 회귀 테스트 | 42건 | **60건** (+18) |
| 응답 정확도(80문항 채점) | 결함 2건 + 위반 다수 | **핵심 결함 0건** |
| 평균 응답 시간 | — | 약 7초 (중앙값 6.5초) |

### 정성 성과
- **재현 가능한 품질 검증 체계 확보**: 향후 가이드 개정·모델 교체 시 동일 절차로 회귀 검증 가능
- **결정적 품질 보장**: 응답 규칙 준수를 생성 모델의 확률적 동작이 아닌 후처리로 보장하여, 어떤 입력에도 사용자 노출 시점 위반 0건
- **부수 결함 선제 발견·수정**: 검증 과정에서 색인 갱신 멱등성 결함 등 잠재 버그를 사전 차단
- **변경 안전성**: 수정 전 정상 응답에 대한 오변환 0건 확인, 회귀 테스트 60건 전수 통과

### 산출물
- 검증 데이터셋 및 자동 검증 절차
- 품질 개선 반영 (코드 6개 모듈, 회귀 테스트 4개 파일)
- 형상관리 반영 완료 (Pull Request 검토·승인·병합)
